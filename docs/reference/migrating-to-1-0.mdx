Most apps only change two version ranges. Your providers, middleware, dashboard routes and the
rest of `config/telescope*.ts` stay as they are. The sections below cover the options that were
removed.

<Callout type="info">
While 1.0 is in release candidate, install it with the `rc` tag:
`pnpm add @adonis-agora/telescope@rc @adonis-agora/telescope-ui@rc`.
</Callout>

## Update the version ranges

A `0.x` range does not match `1.0.0`, and a `2.x` range does not match `3.0.0`, so a plain
update keeps you on the old lines. Change the ranges in `package.json`.

Before:

```json title="package.json"
{
  "dependencies": {
    "@adonis-agora/telescope": "^0.27.1",
    "@adonis-agora/telescope-ui": "^2.1.0"
  }
}
```

After:

```json title="package.json"
{
  "dependencies": {
    "@adonis-agora/telescope": "^1.0.0",
    "@adonis-agora/telescope-ui": "^3.0.0"
  }
}
```

Then install:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">

```sh
npm install
```

</Tab>
  <Tab value="pnpm">

```sh
pnpm install
```

</Tab>
  <Tab value="yarn">

```sh
yarn install
```

</Tab>
</Tabs>

## Run on Node.js 24 or newer

Both packages declare `"engines": { "node": ">=24" }`.

Before:

```txt title=".nvmrc"
22
```

After:

```txt title=".nvmrc"
24
```

Use the same version in your Dockerfile, CI and hosting settings.

## Console access: `credentials` is replaced by `authorize`

`config/telescope_ui.ts` no longer takes `credentials: { token, basic }`, and the console no
longer reads `?token=` or HTTP Basic. Without `authorize`, the console is open outside production
and answers `403` to every request in production. The `TELESCOPE_UI_TOKEN` and
`TELESCOPE_UI_PASSWORD` variables are no longer read; remove them from `start/env.ts` and `.env`.

For token access, use `authorizeByToken`. It reads only the `Authorization: Bearer <token>`
header.

Before:

```ts title="config/telescope_ui.ts"
import env from '#start/env'
import { defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  credentials: {
    token: env.get('TELESCOPE_UI_TOKEN'),
    basic: { username: 'admin', password: env.get('TELESCOPE_UI_PASSWORD') },
  },
})
```

After:

```ts title="config/telescope_ui.ts"
import env from '#start/env'
import { authorizeByToken, defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  authorize: authorizeByToken({ token: env.get('CONSOLE_TOKEN') }),
})
```

```ts title="start/env.ts"
export default await Env.create(new URL('../', import.meta.url), {
  CONSOLE_TOKEN: Env.schema.string(),
})
```

Send the header instead of the query string:

```sh
# Before
open 'https://app.example.com/telescope?token=s3cr3t'
# After
curl -H 'Authorization: Bearer s3cr3t' https://app.example.com/telescope/api/entries
```

For people, gate the console on your app's own auth instead:

```ts title="config/telescope_ui.ts"
import { defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  authorize: (ctx) => ctx.auth.user?.isAdmin === true,
})
```

If you had neither `authorize` nor `credentials`, the console is still open outside production
and still closed in production; it now answers `403` there (it was `401`) and logs a warning at
boot until you set `authorize`.

The JSON errors are now lowercase codes: `{ "error": "forbidden" }` (`403`) and
`{ "error": "unauthenticated" }` (`401`, with `redirectTo` when `authorize` returned one).

## Console access: `dashboardAuth` is removed

The console no longer has its own login. `dashboardAuth` (the login page, the
`<path>/login` and `<path>/logout` routes, the `telescope_dashboard_session` cookie and the
`login` hook) is gone, along with its exports (`resolveDashboardAuth`, `performLogin`,
`readSession`, `decideDashboardAuth`, `enforceDashboardAuth`, `sanitizeReturnTo`,
`renderLoginPage`, `signSessionCookie`, `verifySessionCookie`, `SESSION_COOKIE_NAME` and the
session cookie helpers) and its types. People sign in through your app; `authorize` decides
who gets in and can send anonymous visitors to your login page. Remove
`TELESCOPE_DASHBOARD_SECRET` from `start/env.ts` and `.env`.

Before:

```ts title="config/telescope_ui.ts"
import env from '#start/env'
import User from '#models/user'
import { defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  authorize: () => true,
  dashboardAuth: {
    secret: env.get('TELESCOPE_DASHBOARD_SECRET'),
    async login(email, password) {
      const user = await User.verifyCredentials(email, password)
      return user.isAdmin ? { id: String(user.id), name: user.fullName } : null
    },
  },
})
```

After:

```ts title="config/telescope_ui.ts"
import { defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  authorize: async (ctx) => {
    if (!(await ctx.auth.check())) return { redirectTo: '/login' }
    return ctx.auth.user?.isAdmin === true
  },
})
```

When the console's own API calls get a `401`, the SPA follows the `redirectTo` it carries, or
reloads the page so the server answers it. The access-denied page only shows a "Sign in"
button when you point it at your login page with `accessDenied: { loginHref: '/login' }`.

## Standalone `/telescope/mcp` removed, use the agent hub `/mcp/agora`

Telescope no longer mounts an MCP endpoint of its own. Its tools are served on the Agora dev
endpoint `/mcp/agora`, which `@adonis-agora/agent` provides, behind the console's `authorize`
(see [MCP tools](/docs/telescope/packages/mcp)).

Remove from the app:

- `() => import('@adonis-agora/telescope/mcp_provider')` from `providers` in `adonisrc.ts`;
- `config/telescope_mcp.ts`;
- `TELESCOPE_MCP_TOKEN` from `start/env.ts` and `.env`;
- `/telescope/mcp` from `csrf.exceptRoutes` in `config/shield.ts`, and from any route list that
  skips auth, session or CSP for it;
- any import from `@adonis-agora/telescope/mcp`. `authorizeByToken` is exported by
  `@adonis-agora/telescope/ui`.

To keep a coding agent on Telescope's data, register the agent's MCP provider and point the
client at `/mcp/agora`:

```ts title="adonisrc.ts"
providers: [
  () => import('@adonis-agora/agent/mcp_provider'),
],
```

```sh
claude mcp add --transport http agora http://localhost:3333/mcp/agora
```

Callers are checked by `authorize` in `config/telescope_ui.ts`. A client that sent the old MCP token
sends a token the console accepts instead:

```ts title="config/telescope_ui.ts"
import env from '#start/env'
import { authorizeByToken, defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  authorize: authorizeByToken({ token: env.get('CONSOLE_TOKEN') }),
})
```

```sh
claude mcp add --transport http agora https://app.example.com/mcp/agora \
  --header "Authorization: Bearer $CONSOLE_TOKEN"
```

The tools carry a `telescope_` prefix (`telescope_list_entries`, `telescope_get_trace`, …), and
`telescope_list_entries` returns `{ items, next }`. The doctor checks `telescope.mcp-gate` and
`telescope.mcp-csrf` are gone; drop them from `--only` and CI allowlists.

## OpenTelemetry export moves to `config/otel.ts`

Telescope no longer has an exporter of its own. When the app runs
[`@adonisjs/otel`](/docs/telescope/packages/otel), Telescope sends its entries and AI metrics
through the destinations in `config/otel.ts`, in the same traces as the app's spans. The
endpoint, headers, paths and service name in `config/telescope.ts` are gone, and so is the
`otel.metrics` endpoint block. Boot fails with a message pointing here while any of them is set.

Before:

```ts title="config/telescope.ts"
import { defineConfig } from '@adonis-agora/telescope'
import env from '#start/env'

const posthogKey = env.get('POSTHOG_API_KEY')

export default defineConfig({
  otel: {
    enabled: Boolean(posthogKey),
    endpoint: 'https://us.i.posthog.com',
    tracesPath: '/i/v1/traces',
    logsPath: '/i/v1/logs',
    headers: { Authorization: `Bearer ${posthogKey}` },
    serviceName: 'my-app',
    entryTypes: ['diagnostic', 'exception', 'job'],
  },
})
```

After, install `@adonisjs/otel`:

```sh
node ace add @adonisjs/otel
```

move the endpoint and headers to `config/otel.ts`:

```ts title="config/otel.ts"
import { defineConfig, destinations } from '@adonisjs/otel'
import { telescopeSpanProcessor } from '@adonis-agora/telescope/otel'
import env from '#start/env'

const posthogKey = env.get('POSTHOG_API_KEY')

export default defineConfig({
  serviceName: 'my-app',
  spanProcessors: [telescopeSpanProcessor()],
  destinations: posthogKey
    ? {
        posthog: destinations.otlp({
          endpoint: 'https://us.i.posthog.com/i',
          signals: ['traces', 'logs'],
          headers: { Authorization: `Bearer ${posthogKey}` },
        }),
      }
    : { collector: destinations.otlp({ endpoint: 'http://localhost:4318' }) },
})
```

and keep only the entry types in `config/telescope.ts`, or drop the block to use the default
list:

```ts title="config/telescope.ts"
import { defineConfig } from '@adonis-agora/telescope'

export default defineConfig({
  otel: {
    entryTypes: ['diagnostic', 'exception', 'job'],
  },
})
```

`request`, `query`, `redis`, `http-client` and `log` entries are no longer worth listing:
`@adonisjs/otel` traces HTTP, knex, redis, `fetch` and the logger itself, and listing them sends
each of those operations twice. `telescopeSpanProcessor()` is optional; it brings the app's
OpenTelemetry spans into the Telescope trace view.

You can uninstall the OpenTelemetry packages Telescope used to need, unless the app uses them
directly: `@opentelemetry/sdk-trace`, `@opentelemetry/sdk-trace-base`, `@opentelemetry/sdk-logs`,
`@opentelemetry/sdk-metrics`, `@opentelemetry/resources` and the three
`@opentelemetry/exporter-*-otlp-http` packages.

## `storage.memory({ limit })` is now `maxEntries`

The memory driver takes its cap as `maxEntries`, the same name `InMemoryTelescopeStore` uses.
The value and the default (1000) are unchanged.

Before:

```ts title="config/telescope.ts"
import { defineConfig, storage } from '@adonis-agora/telescope'

export default defineConfig({
  store: 'memory',
  stores: {
    memory: storage.memory({ limit: 5000 }),
  },
})
```

After:

```ts title="config/telescope.ts"
import { defineConfig, storage } from '@adonis-agora/telescope'

export default defineConfig({
  store: 'memory',
  stores: {
    memory: storage.memory({ maxEntries: 5000 }),
  },
})
```

## The dashboard reads its API base from the page only

The dashboard takes its API base from the config block the provider writes into the page, or
falls back to `<mount>/api`. It no longer reads a `window.__TELESCOPE_DASHBOARD_BASE__` global.
If you embed the client yourself, pass the base to it.

Before:

```ts title="resources/js/telescope.ts"
import { TelescopeClient } from '@adonis-agora/telescope-ui/client'

window.__TELESCOPE_DASHBOARD_BASE__ = '/admin/telescope/api'
const telescope = new TelescopeClient()
```

After:

```ts title="resources/js/telescope.ts"
import { TelescopeClient } from '@adonis-agora/telescope-ui/client'

const telescope = new TelescopeClient({ baseUrl: '/admin/telescope/api' })
```

## `coverage.legacyAgentLib` is gone from the AI summary

The AI summary (`GET <path>/api/metrics/ai`, `TelescopeClient#ai()`, and the `AiCoverage` type)
no longer has a `legacyAgentLib` flag. It marked apps running an `@adonis-agora/agent` release
older than 0.93.0. Read `usageEvents` instead: zero means no `usage.recorded` events in the
window.

Before:

```ts title="app/controllers/ai_report_controller.ts"
import type { HttpContext } from '@adonisjs/core/http'
import { TelescopeClient } from '@adonis-agora/telescope-ui/client'

export default class AiReportController {
  async show({ response }: HttpContext) {
    const ai = await new TelescopeClient({ baseUrl: 'http://localhost:3333/telescope/api' }).ai()
    if (ai.coverage.legacyAgentLib) return response.ok({ status: 'agent too old' })
    return response.ok({ spend: ai.spend.totalUsd })
  }
}
```

After:

```ts title="app/controllers/ai_report_controller.ts"
import type { HttpContext } from '@adonisjs/core/http'
import { TelescopeClient } from '@adonis-agora/telescope-ui/client'

export default class AiReportController {
  async show({ response }: HttpContext) {
    const ai = await new TelescopeClient({ baseUrl: 'http://localhost:3333/telescope/api' }).ai()
    if (ai.coverage.usageEvents === 0) return response.ok({ status: 'no usage recorded' })
    return response.ok({ spend: ai.spend.totalUsd })
  }
}
```
