A coding agent can read what Telescope recorded — requests, queries, exception stacks, trace
waterfalls, the Pulse health rollup — over the [Model Context Protocol](https://modelcontextprotocol.io),
and answer *"why is `POST /checkout` slow?"* by listing the slow requests, pulling the trace
waterfall and reading the queries. It reads the same redacted, sampled entries the dashboard reads.

## Use it through `/mcp/agora`

With `@adonis-agora/agent/mcp_provider` in `adonisrc.ts`, the app serves the Agora developer
endpoint `/mcp/agora`, and Telescope's tools are on it with nothing to configure. Add it to your
client:

```sh
claude mcp add --transport http agora http://localhost:3333/mcp/agora
```

With `@adonis-agora/authkit-server` in the app (and `mcp: true` in `config/authkit.ts`), the client
opens the login in your browser and you sign in like you do on the console. Each call is then
checked by the **console's** `authorize` (`config/telescope_ui.ts`), so whoever can open
`/telescope` can use the tools, and nobody else. When the console uses `authorizeByToken`, send that
token instead:

```sh
claude mcp add --transport http agora http://localhost:3333/mcp/agora \
  --header "Authorization: Bearer $CONSOLE_TOKEN"
```

See [Dev tools over MCP](/docs/agent/dev-tools) for the endpoint itself. Turning the console off
(`telescope_ui.enabled: false`) also takes Telescope's tools off `/mcp/agora`.

## The tools

| Tool | Args | Returns |
| --- | --- | --- |
| `telescope_list_entries` | `type?`, `search?`, `tag?`, `sinceMinutes?`, `limit?`, `page?` | Recent entries, newest first, as `{ items, next }` (default 20, max 100). |
| `telescope_get_entry` | `id` | One entry plus its trace siblings (the request/job waterfall context). |
| `telescope_get_trace` | `traceId` | Every entry recorded under one trace id, newest first. |
| `telescope_get_waterfall` | `traceId` | The span waterfall for a trace (each operation as a start/duration span). |
| `telescope_get_health` | `sinceMinutes?` (default 60) | The [Pulse](/docs/telescope/packages/pulse) health snapshot over a trailing window. |
| `telescope_diagnose_exception` | `id` | The [AI diagnosis](/docs/telescope/packages/ai) for an exception entry (probable cause / fix). Listed only when AI diagnosis is configured. |
