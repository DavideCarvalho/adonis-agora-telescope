This subpath is the dashboard's read backend. It mounts a JSON API and an SSE live-stream
directly onto your AdonisJS router — no separate service — all served from the headless
[`TelescopeService`](/docs/telescope/packages/core#headless-api), behind a configurable
[auth guard](/docs/telescope/dashboard/auth). The dashboard **page** itself is the
[`@adonis-agora/telescope-ui`](/docs/telescope/packages/telescope-ui) SPA, a pre-built React
bundle that consumes these routes.

## Install

The dashboard ships inside the one `@adonis-agora/telescope` package. Enable it when configuring
telescope:

<Tabs items={['npm', 'pnpm', 'yarn']}>
  <Tab value="npm">

```sh
npm i @adonis-agora/telescope
node ace configure @adonis-agora/telescope   # then pick "UI" at the prompt
```

</Tab>
  <Tab value="pnpm">

```sh
pnpm add @adonis-agora/telescope
node ace configure @adonis-agora/telescope   # then pick "UI" at the prompt
```

</Tab>
  <Tab value="yarn">

```sh
yarn add @adonis-agora/telescope
node ace configure @adonis-agora/telescope   # then pick "UI" at the prompt
```

</Tab>
</Tabs>

Selecting **UI** registers `@adonis-agora/telescope/ui_provider` and publishes
`config/telescope_ui.ts`. Open `http://localhost:3333/telescope`.

## How it mounts

On boot the provider:

1. reads `config/telescope_ui.ts`;
2. resolves the live store from the core's runtime slot (same handle the watchers record
   through — no DI);
3. registers routes under the configured prefix via the AdonisJS router — the JSON API under
   `<path>/api/*`, the SSE stream at `<path>/api/stream` (plus optional `dashboardAuth`
   login/logout routes), each behind the `authorize` guard. It does **not** serve a page at
   the prefix root; the [`@adonis-agora/telescope-ui`](/docs/telescope/packages/telescope-ui)
   SPA provider owns `<path>` and `<path>/*`.

<Callout type="warn">
If `@adonis-agora/telescope` isn't enabled/booted, the store slot is `null` and the provider
registers **no routes** (warn-logged) rather than crashing — the dashboard simply doesn't
exist until the core is running.
</Callout>

## What it serves

| Route                              | Serves                                                       |
| ---------------------------------- | ----------------------------------------------------------- |
| `GET <path>/api/entries`           | List (filterable, capped). Compact `EntrySummary` rows.     |
| `GET <path>/api/entries/:id`       | One entry with full `content`, or 404.                      |
| `GET <path>/api/trace/:traceId`    | Every entry on a trace.                                     |
| `GET <path>/api/stats`             | `{ count, topFamilies, topTags }`.                          |
| `GET <path>/api/stream`            | SSE live-tail of newly recorded entries.                    |
| `GET <path>/api/metrics/stats\|timeseries\|traces\|waterfall/:traceId\|n-plus-one/:traceId` | Metrics analytics used by the SPA. |
| `GET <path>/api/metrics/pulse` *(if Pulse enabled)* | Pulse rollup snapshot.                        |
| `POST <path>/api/requests/:id/replay` *(if replay enabled)* | Replay a captured request.        |
| `GET <path>/api/meta` *(if any extension)*           | Contributed dashboards + entry types.     |
| `GET <path>/api/ext/:ext/data/:provider` *(if any extension)* | One data provider's result.      |

The dashboard HTML is read once per process and cached; the API base path is injected into
it at render time. See the [dashboard tour](/docs/telescope/dashboard) for the full API
shape and query parameters.

## Configuration

```ts title="config/telescope_ui.ts"
import { defineConfig } from '@adonis-agora/telescope/ui'

export default defineConfig({
  enabled: true,
  path: '/telescope',
  // authorize: (ctx) => ctx.auth?.user?.isAdmin === true,
  // credentials: { token: env.get('TELESCOPE_UI_TOKEN') },
})
```

| Key           | Default        | Description                                                       |
| ------------- | -------------- | --------------------------------------------------------------- |
| `enabled`     | `true`         | Master switch; `false` registers no routes.                    |
| `path`        | `/telescope`   | URL prefix (normalized to leading slash, no trailing slash).   |
| `authorize`   | default policy | Access-decision hook — [Dashboard auth](/docs/telescope/dashboard/auth). |
| `credentials` | `{}`           | Built-in token / HTTP Basic gate for the default policy.        |

## Build your own UI

The data lives behind the documented JSON API, so the shipped dashboard is optional.
Disable it and point your own front end (an admin page, a Grafana panel, a CLI) at the same
`<path>/api/*` endpoints, or read `TelescopeService` directly. The `@adonis-agora/telescope/ui`
subpath also exports its framework-light building blocks — `TelescopeApi`,
`renderDashboard`, the `enforceGuard` guard, and `toSummary` / `buildQuery` helpers — if you
want to assemble a custom mount.

## Peer dependencies

Only `@adonisjs/core` (`^7.3.0`), which the core already requires. This subpath ships no
front-end — it is the JSON API/SSE backend. The React SPA lives in the separate
`@adonis-agora/telescope-ui` package, published pre-built.
